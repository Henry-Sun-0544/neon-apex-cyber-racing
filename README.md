# Neon Apex: Cyber Racing

**霓虹之巅：赛博竞速** · 简称 **NA:CR**

一个完全在浏览器中运行的 3D 赛博朋克赛车游戏。赛道、城市、赛车、粒子、音乐与音效**全部由代码程序化生成**，不依赖任何外部模型、贴图或音频素材。

技术栈：**Vite + TypeScript + Three.js**（无 React/Vue 等框架，UI 为原生 HTML/CSS）。

---

## 快速开始

```bash
cd neon-apex-cyber-racing
npm install
npm run dev
```

然后在浏览器中打开终端输出的地址（默认 <http://127.0.0.1:5173/>），点击 **START RACE** 即可开始。

其它命令：

```bash
npm run build      # 类型检查 (tsc --noEmit) + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
npm run typecheck  # 只做类型检查
```

## 操作说明

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车；低速时倒车 |
| `A` / `D` / `←` / `→` | 转向（转向力度随车速下降，高速更"重"） |
| `空格` | 氮气（按住消耗能量条，松开后自动回充） |
| `R` | 重新开始本局 |
| `C` | 切换第三人称 / 引擎盖视角 |
| `M` | 静音 / 取消静音 |
| `Esc` | 返回主菜单 |

比赛默认 **3 圈**、**5 名 AI 对手**（共 6 辆车），可在主菜单中调整圈数与 AI 数量。

## 玩法系统

- **程序化闭环赛道**：CatmullRom 闭合曲线生成约 1661 m 的赛道，包含路面、裙边、护栏、发光霓虹边线、12 道检查点门架与起终点棋盘格；赛道带高低起伏，车辆会随路面俯仰。
- **加速带**：赛道上的发光箭头区域，压上后获得短时推力、氮气补充与粒子爆发。
- **氮气**：能量条 + 按住空格消耗；提供额外推力、更低的横向抓地（更容易漂移）、FOV 拉伸与尾焰粒子，耗尽后自动回充。
- **AI 对手**：每名 AI 拥有独立的速度系数、走线偏好、摆动幅度、失误概率与氮气技巧；会按赛道曲率减速、寻找内线 apex、避让前车，并有橡皮筋机制与卡死自救。
- **计时与排名**：总时间、当前圈时间、最佳圈速、实时名次；完成设定圈数后结算。
- **碰撞**：与建筑、路面霓虹柱、护栏、AI 车辆均有碰撞检测，触发减速、弹开、火花粒子与屏幕震动。护墙为**按时间速率的刮擦减速**，贴着护栏不会把车"粘死"；若车被护栏与立柱夹在死角，只要还踩着油门，救援推力会**逐次加强**直至脱困（也可以用 `S` 倒车退出）。
- **粒子系统**：氮气尾焰、碰撞火花、加速带光点、环境尘埃共 4 个对象池，游标轮转复用，运行时不分配新对象。
- **音频**：Web Audio API 程序化合成。BGM 为 128 BPM 的 synthwave 循环（Am–F–C–G 和声进行，含底鼓/拍手/踩镲/贝斯/Pad/拨弦），另有倒计时、氮气、碰撞、加速带、圈速、结算等音效与随速度变化的引擎声。需用户点击开始后才初始化 `AudioContext`（浏览器自动播放策略）。所有一次性声源播放完毕即自动断开，拨弦共用一条延迟线，且调度器**不会为卡顿期间错过的节拍补课**——避免长时间运行后音频节点堆积拖垮主线程。
- **画面**：暗色城市峡谷 + 程序化楼群窗户与霓虹招牌 + 体积雾 + 天空穹顶；`UnrealBloomPass` 辉光后处理，并带**性能自监控**——连续采样低于阈值时自动关闭 Bloom 并降低像素比。

## 项目结构

```
neon-apex-cyber-racing/
├── index.html                 # 页面骨架：canvas、HUD、菜单、倒计时、结算界面
├── package.json
├── vite.config.ts
├── tsconfig.json
├── tools/
│   └── smoke-test.mjs         # 无头 Chrome + CDP 端到端冒烟测试
└── src/
    ├── main.ts                # 入口：URL 参数解析、错误收集、启动 Game
    ├── styles.css             # 原生 CSS 赛博朋克 UI（扫描线、霓虹、HUD）
    └── game/
        ├── Config.ts          # 唯一调参中心（车辆/AI/相机/渲染/音频/粒子）
        ├── Types.ts           # 共享类型（StaticBox / HudState / CollisionEvent）
        ├── Utils.ts           # clamp/lerp/damp/格式化时间/可复现随机数
        ├── Game.ts            # 编排器：主循环、状态机、HUD 刷新、热键
        ├── GameState.ts       # 比赛状态：圈数、计时、过线检测、排名、结算
        ├── Input.ts           # 键盘输入（含边沿触发与 blur 清理）
        ├── SceneManager.ts    # 渲染器、雾、天空、灯光、Bloom、跟随相机
        ├── Track.ts           # 程序化赛道几何 + 投影查询（O(1) 带 hint）
        ├── City.ts            # 程序化城市：楼群、招牌、路灯、霓虹柱、碰撞盒
        ├── CarModel.ts        # 程序化低多边形赛车模型 + 轮组骨架
        ├── VehicleBase.ts     # 共享街机物理（推力/阻力/抓地/漂移/氮气）
        ├── PlayerVehicle.ts   # 玩家车：加速带、尾焰、刹车灯
        ├── AIVehicle.ts       # AI 车辆
        ├── AIController.ts    # AI 驾驶策略与车手档案
        ├── CollisionSystem.ts # 空间哈希：贴地/护墙/建筑/车车碰撞 + 自救
        ├── ParticleSystem.ts  # 4 个 GPU 粒子池（单 ShaderMaterial）
        ├── AudioManager.ts    # 程序化 BGM 与音效合成
        └── UIManager.ts       # 菜单/HUD/倒计时/结算 + Canvas 小地图
```

## 调试参数（URL query）

| 参数 | 作用 |
| --- | --- |
| `?autostart=1` | 跳过开始菜单直接开赛 |
| `?nocount=1` | 跳过 3-2-1 倒计时（隐含 autostart） |
| `?autopilot=1` | 观战模式：由 AI 驾驶玩家车辆（隐含 autostart） |
| `?laps=N` | 覆盖比赛圈数 |
| `?lowfx=1` | 低画质预设：关闭 Bloom、像素比锁 1、粒子池减为 1/4（供软件渲染/低端设备与自动化测试使用） |

运行时调试句柄：浏览器控制台中的 `window.__NACR__`（只读快照 `phase/speedKmh/lap/rank/raceTime/nitro/boosting/particles/bloom/fps/...`，以及 `start()` / `restart()`）。

### 自动化测试

```bash
npm run dev            # 另开一个终端保持运行
node tools/smoke-test.mjs
```

脚本会启动无头 Chrome，通过 CDP 分三个阶段验证（当前 **25/25 通过**）：

1. `?autopilot=1&lowfx=1` 全自动跑完一整局，校验 AI 数量、HUD、车速、粒子、圈数、名次与结算表；
2. 合成按键驾驶（`W` / `空格` / `D` / `S` / `R`），校验加速、氮气消耗、转向导致的**车头偏航角变化**、刹车、HUD 与实际状态一致、重开归零；
3. 独立标签页在全特效下按 `W`+`空格` 驾驶并截图，作为视觉证据（无断言，失败不影响结论）。

阶段 1/2 通过 `document.title` 累积日志回读样本（`/json/list` 通道），因此渲染器再忙也不会丢数据；截图固定走默认 `fromSurface` 抓取。`ONLY=1|2|3` 可只跑单个阶段。

## 已知限制

- 无音轨文件，音乐为实时合成，音色偏简单（合成器音色而非采样音色）。
- 车辆为低多边形程序化模型，无悬挂/轮胎形变等精细模拟。
- 碰撞体使用盒体与圆柱近似，极端角度下可能有轻微穿插。
- 阴影贴图默认关闭以保性能，主要靠自发光与 Bloom 表现光照。
- 软件渲染（SwiftShader）环境下帧率约 20 FPS，游戏内时钟会因 `dt` 上限（1/20 s）慢于真实时间；**真实 GPU 环境实测稳定 60 FPS**（`autopilot` 自动跑圈、275 km/h、约 700 个存活粒子、Bloom 开启，无控制台报错）。
